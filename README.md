# portfolio-site

> 🎓 Personal portfolio site for Kaleeswaran — clean dark single-page HTML/CSS.
> No frameworks, no build step. Open `index.html` in a browser.

## Run
Just open `index.html`. Or serve it:
```bash
python -m http.server 8000
# visit http://127.0.0.1:8000
```

## Sections
- Hero (name + tagline)
- About
- Projects
- Skills
- Connect (GitHub / Instagram / Email)

## Deploy
Push to GitHub and enable Pages (Settings → Pages → main branch), or drop on
any static host (Netlify, Vercel, GitHub Pages).
